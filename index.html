System Details (FAQ)

Everything you need to know about how GHN Library operates.

Is this repository free to use? +
Absolutely. GHN Library is built as an open-source initiative. It relies entirely on free infrastructure provided by GitHub and community contributions. You will never be charged to access the source URL.
How often do the apps get updated? +
The repository is maintained by an automated CI/CD pipeline (GitHub Actions). The scripts run continuously, compiling and merging data from over 58 trusted sources every 24 hours to ensure you have the latest app versions.
Does this work with my device's UDID being cooling off? +
This repository strictly provides the IPA files (the apps themselves). It does not bypass Apple's 30-day cooling-off period or hardware locks. You still need a valid certificate or a working sideloading method to install these apps.
