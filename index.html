Frequently Asked Questions

Is this repository free? +
Yes, 100% free and open-source. Hosted entirely on GitHub Pages.
Do I need a computer to use this? +
No. While it works with PC-based tools like AltStore, you can use the link directly on your iPhone via ESign or Scarlet.
Does this bypass Apple's cooling-off period? +
No, this is only an app library (IPA files). You still need a valid certificate to install them.
