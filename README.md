Repositori gabungan (*All-in-one*) untuk berbagai aplikasi iOS. Repositori ini dikonfigurasi khusus untuk mendukung **AltSources** secara penuh.

## ✨ Fitur Utama
* **Integrasi AltStore:** File `repo.json` sudah disesuaikan dengan format standar AltSources.
* **Auto-Merge:** Menggunakan skrip `merge.py` untuk menggabungkan berbagai *source* secara otomatis.
* **Workflow Otomatis:** Pembaruan ditenagai langsung oleh GitHub Actions.
