An all-in-one aggregated repository for iOS apps, games, and tweaks. Configured to be fully compatible with standard **AltSources** and **ESign** formats.

---

###  How to Use (Sideloading)
Copy the URL below and add it to the **Sources** menu in your preferred signer app:

```text
(https://raw.githubusercontent.com/RadhityaOG/IPA-Libary/refs/heads/main/repo.json)
```
___

###  Key Features
* **Auto-Merge:** Automatically aggregates apps from all 58+ external IPA sources using `merge.py` with built-in duplicate filtering.
* **24/7 Auto-Update:** The catalog updates automatically via GitHub Actions.
