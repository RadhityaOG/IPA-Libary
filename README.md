Repositori gabungan (*All-in-One*) untuk berbagai aplikasi dan tweak iOS. Dikonfigurasi khusus agar kompatibel penuh dengan format standar **AltSources** dan **ESign**.

### ✨ Fitur Utama
* **Multi-Signer Ready:** File `repo.json` kompatibel untuk FlekSt0re, ESign, AltStore, SideStore, dan Feather.
* **Auto-Merge:** Menggabungkan puluhan sumber repositori IPA secara otomatis menggunakan skrip `merge.py` dengan sistem filter duplikat.
* **Auto-Update 24/7:** Pembaruan katalog berjalan otomatis setiap 12 jam sekali lewat GitHub Actions.

### 🚀 Cara Penggunaan (Sideloading)
