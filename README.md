An all-in-one aggregated repository for iOS apps, games, and tweaks. Configured to be fully compatible with standard **AltSources** and **ESign** formats.

###  Key Features
* **Multi-Signer Ready:** The `repo.json` file is compatible with FlekSt0re, ESign, AltStore, SideStore, and Feather.
* **Auto-Merge:** Automatically aggregates dozens of external IPA sources using `merge.py` with built-in duplicate filtering.
* **24/7 Auto-Update:** The catalog updates automatically every 12 hours via GitHub Actions.

###  How to Use (Sideloading)
Copy the URL below and add it to the **Sources** menu in your preferred signer app (**FlekSt0re**, **ESign**, **AltStore**, **SideStore**, or **Feather**):

(https://raw.githubusercontent.com/RadhityaOG/IPA-Libary/main/repo.json)
